# Ember-2 v0.9.0 — First Feature-Complete Release

**Released:** 2026-03-24

The first release where all core systems are working together as a usable product.

## What's In This Release

### Core Systems
- **Append-only memory vault** — JSON-based, typed memory storage
- **SQLite vector store** — 16,728 ingested records searchable via semantic retrieval
- **Context assembly pipeline** — intent classification, policy-weighted ranking, diversity selection
- **Reflection engine** — daily and weekly reflections from journal and ingested content
- **State layer** — StateService, StateResolver, 8 state categories
- **Constitutional review** — post-draft safety review with 7 principles

### Ingestion
- ChatGPT export import, PDF, DOCX, CSV, Google Drive importers
- Corpus quality suppression — 3,574 low-quality records flagged

### Intelligence
- Web search via local SearXNG
- Vision model support
- Onboarding flow for new users
- Profile retrieval with score gating
- Runtime model switching
- Context compression at 70% buffer capacity

### Interface
- FastAPI + Open WebUI (OpenAI-compatible adapter)
- Custom WebUI branding
- Docker Compose for SearXNG + Open WebUI

### Security
- API key auth via Windows Credential Manager
- Tailscale-only binding, rate limiting, audit logging

### Developer Experience
- 123 tests passing
- Retrieval evaluation harness (5 benchmark cases)
- Setup wizard and SETUP.md guide
