# Ember-2 v0.9.1 — Conversation Persistence

**Released:** 2026-03-24

The session system that makes conversations retrievable and browsable.

## What Changed

- Conversation turns tracked by `session_id` in metadata
- Session records stored in `memory/session/` (append-only)
- Auto-title from first user message (first 50 chars)
- Soft delete and rename via new session records
- `updated_at` and `turn_count` derived at read time
- New endpoints for conversation listing and detail
- README: added installer download link
