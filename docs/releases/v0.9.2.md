# Ember-2 v0.9.2 — Sessions, File Upload, Health Check

**Released:** 2026-03-24

Conversation persistence and file upload arrive.

## What Changed

- **Conversation sessions** — every chat turn carries a `session_id` linking turns to named conversations
- **Session records** in `memory/session/` — append-only, rename, soft-delete
- **Auto-titling** from first 50 characters of first user message
- **CRUD endpoints** — `GET/PATCH/DELETE /v1/conversations`, `GET /v1/conversations/{id}`
- **`X-Session-ID` header** — UI-generated or auto-generated
- **`POST /ingest/upload`** — multipart file upload; `.pdf/.docx/.csv/.xlsx` ingested, images returned as base64
- **Health check** — `GET /` returns current model name
- **CORS middleware** for development
- `python-multipart` added to requirements
- Fixed `session.py` import bug
- 138 tests passing (15 new)
