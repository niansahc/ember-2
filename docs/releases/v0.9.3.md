# Ember-2 v0.9.3 — Projects

**Released:** 2026-03-24

Conversations can now be grouped into projects with full CRUD support.

## What Changed

- **Project CRUD** — `GET/POST /v1/projects`, `PATCH/DELETE /v1/projects/{id}`
- **Conversation assignment** — `PATCH /v1/conversations/{id}` accepts `project_id`
- **Project conversations** — `GET /v1/projects/{id}/conversations`
- **Session project support** — sessions carry `project_id` in metadata
- Same append-only resolution pattern as sessions: latest record per project_id wins
- 153 tests passing (15 new for projects)
