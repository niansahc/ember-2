# Ember-2 v0.9.4 — Ember Gets Her Own Home

**Released:** 2026-03-27

The release where Open WebUI was removed and Ember got her own custom UI served directly from FastAPI.

## What Changed

**One process, one port, one URL.** Ember's UI is now served by the same FastAPI process as the API. No more Docker container for Open WebUI, no more port juggling, no CORS issues. Start `start_api.bat` and open `http://localhost:8000`.

**Full conversation text stored.** The 300-character truncation on conversation writes was removed. Every turn is saved in full — user messages no longer vanish on reload.

**API key setup improved.** `scripts/set_api_key.py` now supports `--check` and `--non-interactive` flags, enabling the installer to handle key setup without hanging on interactive prompts.

**All docs updated.** CLAUDE.md, README.md, SETUP.md, and the TDD all reflect the new architecture. Open WebUI references removed throughout.

## Technical Details

- FastAPI serves built UI from `ui/` folder at same port as API
- `GET /` returns `index.html` when `ui/` exists, JSON health check otherwise
- New `GET /api/health` endpoint always returns JSON
- Auth: only API routes require key — UI/static assets are public
- Removed: `Dockerfile.webui`, `webui/` folder, Open WebUI Docker service
- `docker-compose.yml`: SearXNG only
- 153 tests passing
